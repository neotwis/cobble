## About Cobble

Cobble is a browser extension built to give you a simpler, cleaner, and more personal browsing experience.

It brings useful tools and customization options together in one place, helping you organize your browsing space and make every new tab feel like your own.

## Installation

### Google Chrome

You can install Cobble manually using the ZIP package.

1. [Download Cobble ZIP](https://github.com/neotwis/cobble/archive/refs/heads/main.zip).
2. Open your Downloads folder and locate `cobble.zip`.
3. Extract the ZIP file.
4. Open Chrome and navigate to `chrome://extensions/`.
5. Enable **Developer mode** in the top-right corner.
6. Click **Load unpacked**.
7. Select the extracted `cobble` folder containing `manifest.json`.

  <img src="https://img.shields.io/badge/Chrome-Developer%20Mode-2E8B57?style=for-the-badge&logo=googlechrome&logoColor=white" alt="Chrome Developer Mode" />

## Development

### Requirements

- Node.js
- npm
- Git

### 1. Clone the repository

```bash
git clone https://github.com/neotwis/cobble.git
cd cobble
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start development

```bash
npm run dev
```

### 4. Build the extension

```bash
npm run build
```

After building, load the generated extension folder through your browser's extension management page.
